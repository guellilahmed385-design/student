MATHEMATICS

Analyse 1

CP1

Résumé essentiel

  • Limite : étudier le comportement de f(x) lorsque x tend vers a ou ±∞.
  • Continuité en a : f(a) existe et lim(x→a) f(x) = f(a).
  • Dérivabilité : f'(a) est la limite du taux d’accroissement si elle existe.
  • Variations : le signe de f' permet d’étudier les intervalles de croissance et décroissance.
(uv)' = u'v + uv'   ·   (u/v)' = (u'v−uv')/v²

Exercice 1 · Dérivation

Calculer la dérivée de f(x) = x² − 3x + 2.

Par linéarité : f'(x) = 2x − 3. Donc f'(2) = 1.

PHYSICS

Électrostatique

CP1

Résumé essentiel

  • La charge électrique se mesure en coulombs (C).
  • La loi de Coulomb donne la force entre deux charges ponctuelles.
  • Le champ électrique caractérise l’action électrique par unité de charge test positive.
  • Le potentiel électrique est une grandeur scalaire.
F = (1 / 4πε₀) · |q₁q₂| / r²

Exercice 1 · Loi de Coulomb

Comment varie la valeur de la force si la distance r est doublée, toutes les autres grandeurs restant constantes ?

La force est proportionnelle à 1/r². Si r devient 2r, la force devient F/4.

PHYSICS

Thermodynamique

CP1

Résumé essentiel

  • Un système thermodynamique est décrit par des variables d’état (P, V, T…).
  • Pour un gaz parfait : PV = nRT.
  • Le premier principe exprime la conservation de l’énergie.
  • Il faut préciser la convention de signe utilisée pour le travail et la chaleur.
PV = nRT   ·   ΔU = Q + W (convention récepteur)

Exercice 1 · Gaz parfait

À quantité de matière et température constantes, si le volume double, que devient la pression ?

Avec PV = constante (loi de Boyle-Mariotte), P₂ = P₁/2 : la pression est divisée par deux.

MATHEMATICS

Probabilités & statistique

CP1

Résumé essentiel

  • Un événement est un sous-ensemble de l’univers Ω.
  • Pour des événements A et B : P(A∪B)=P(A)+P(B)−P(A∩B).
  • Si A et B sont indépendants : P(A∩B)=P(A)P(B).
  • La moyenne d’une série est la somme des valeurs divisée par l’effectif total.
E(X) = Σ xᵢP(X=xᵢ)

Exercice 1 · Probabilité

Un dé équilibré est lancé. Quelle est la probabilité d’obtenir un nombre pair ?

Les issues favorables sont {2,4,6}, soit 3 issues sur 6. P = 3/6 = 1/2.

COMPUTER SCIENCE

Algorithmique

CP1

Résumé essentiel

  • Un algorithme décrit une suite finie d’étapes pour résoudre un problème.
  • Les structures de base : séquence, condition (SI), boucle (POUR / TANT QUE).
  • Une variable stocke une valeur ; son type définit les opérations possibles.
  • Tester les cas limites aide à vérifier un algorithme.
SI condition ALORS … SINON … FIN SI

Exercice 1 · Boucle

Quelle valeur est affichée par : s ← 0 ; POUR i de 1 à 4 : s ← s+i ; afficher(s) ?

Les additions donnent 1 + 2 + 3 + 4 = 10. La valeur affichée est 10.

COMPUTER SCIENCE

Architecture des ordinateurs

CP1

Résumé essentiel

  • Le processeur (CPU) exécute les instructions.
  • L’unité de contrôle orchestre leur exécution ; l’UAL réalise les opérations arithmétiques et logiques.
  • La mémoire stocke les données et instructions ; distinguer mémoire volatile et non volatile.
  • Le cycle d’instruction comprend généralement recherche, décodage et exécution.
Cycle : Fetch → Decode → Execute

Exercice 1 · Mémoire

La RAM est-elle volatile ou non volatile ?

La RAM est une mémoire volatile : son contenu est généralement perdu lorsque l’alimentation est coupée.
